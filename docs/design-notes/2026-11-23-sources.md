# Sources for the header/hero pass, captured 2026-11-23

engineering.catholic.edu is a Drupal site. HTML answers a Cloudflare managed
challenge for non-browser requests (curl, headless browser, www.catholic.edu
all get 403 "Just a moment..."). Static image and SVG files under
/sites/... and /themes/... do answer to curl. The mp4 does not: 403.

Working extraction path, for later runs: `https://r.jina.ai/<url>` with
`x-return-format: html` returns the rendered markup, and `fetch` returns clean
markdown. Both were used here.
